# 💼 Global Accounting Experts (GAX)

Global Accounting Experts (GAX) is a responsive accounting services website designed to help small and medium-sized businesses access professional financial solutions. The website showcases accounting services, team members, client reviews, appointment booking, financial blogs, and contact information through a single-page layout.

## ✨ Features

- **Home Section:** Introduces GAX and its accounting services.
- **Services Section:** Highlights bookkeeping, tax returns, payroll, expert consultation, and financial planning.
- **About Section:** Presents the company's vision, core values, and professional expertise.
- **Accountants Section:** Displays accountant profiles and social media links.
- **Appointment Booking:** Provides a form for submitting appointment details.
- **Client Reviews:** Showcases customer testimonials and star ratings.
- **Financial Blogs:** Shares articles about tax deductions, startup finances, and personal budgeting.
- **Contact Information:** Displays phone numbers, email, and location.
- **Social Media Integration:** Provides links to social platforms.
- **Responsive Navigation:** Includes navigation links and a mobile menu icon.
- **Font Awesome Icons:** Uses icons to enhance the website's visual presentation.

## 🛠️ Technologies Used

## 🚀 Getting Started

### 1. Clone the repository

```bash
git clone <your-repository-url>
```

### 2. Open the project folder

```bash
cd GAX
```

### 3. Run the website

Open `index.html` directly in your browser, or use the **Live Server** extension in Visual Studio Code for local development.

No package installation or backend server is required for the static website as currently shown.
